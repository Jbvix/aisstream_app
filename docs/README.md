# Documentacao do Projeto

Este diretorio concentra a documentacao tecnica e operacional do `aisstream_app`.

## Estrutura
- `ARQUITETURA_E_IMPLANTACAO.md`: **documento do desenvolvedor** — diagrama de implantacao, arvore de diretorios, modulos, fluxos, endpoints, env e deploy.
- `MANUAL_GRAFO_E_FUNCIONALIDADES.md`: **documento do usuario** — Grafo Estrategico (cores, navegacao, casos de uso) e aplicacoes futuras.
- `OBSIDIAN_REMOTELY_SAVE_TUTORIAL.md`: configuracao da integracao com o Obsidian (Supabase + Remotely Save).
- `PROPOSTA_KRATOS.md`: proposta de evolucao do produto (UX/UI, inteligencia estrategica, roadmap).
- `CONFIGURACAO_XAI_E_VOZ.md`: configuracao do xAI (Grok) no servidor e voz do KRATOS (fala/escuta).
- `DEPLOY_PULL_CPANEL.md`: fluxo de pull/deploy GitHub -> cPanel (configurado).
- `relatorios/`: relatorios de fim de etapa (implementacoes, melhorias, correcoes, licoes).
- `adr/`: decisoes arquiteturais (Architecture Decision Records).
- `api/`: contrato da API (OpenAPI).
- `runbooks/`: operacao em producao e resposta a incidentes.
- `faq.md`: problemas recorrentes e solucao rapida.
